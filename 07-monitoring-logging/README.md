# 07 - Monitoring & Logging

## What this shows
End-to-end observability using metrics and logs for containerized workloads.

## Tech stack
- Prometheus
- Grafana
- Elasticsearch
- Kibana
- Filebeat
- Docker Compose

## Architecture
- Metrics: Node Exporter → Prometheus → Grafana
- Logs: Docker → Filebeat → Elasticsearch → Kibana

## Key concepts demonstrated
- Metrics scraping and visualization
- Centralized logging
- Observability pipelines
