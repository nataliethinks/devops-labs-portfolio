# 03 - Docker Networking & Compose

## What this shows
Multi-container application setup using Docker Compose with a user-defined bridge network, enabling container-to-container communication.

## Tools
- Docker
- Docker Compose

## Scenario
- Web container communicates with another container via Docker network
- Services defined and managed using docker-compose.yml

## Outcome
Containers were able to communicate over a custom Docker network without exposing internal ports.
