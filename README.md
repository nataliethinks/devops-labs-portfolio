# Overview

This repository contains a collection of hands-on DevOps and cloud-native labs demonstrating practical experience with containerization, orchestration, infrastructure concepts, and observability.

All labs were executed in a **local development environment** using Docker Desktop and Minikube to demonstrate **production-relevant patterns independent of cloud vendor lock-in**.

## Tech

- **Version Control:** Git, GitHub  
- **Containers:** Docker, Docker Compose  
- **Orchestration:** Kubernetes (Minikube)  
- **Infrastructure Concepts:** Volumes, Persistent Storage  
- **Monitoring:** Prometheus, Grafana  
- **Logging:** Filebeat, Elasticsearch, Kibana  
- **OS / Environment:** macOS, Linux containers
